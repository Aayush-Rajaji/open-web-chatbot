Build Your Own Hybrid Website Chatbot

Drop a fast, privacy-first AI assistant onto any website in 3 lines of HTML. Instant canonical answers at $0, optional Gemini / OpenRouter LLM fallback, and full static mode for GitHub Pages.

1. Zero Build Bloat

Pure vanilla HTML, CSS, and JavaScript. No React runtime, no bundlers, and no third-party tracking scripts.

2. 3-Layer Hybrid Engine

Answers frequent FAQs in under 10ms locally, caches repeated AI queries for 30 minutes, and cascades Gemini to OpenRouter.

3. Safe Git Workflow

Single-file config, `.env.local` protection, and a built-in PII/secret scanner so API keys never leak into commits.

Embed on any page in 3 lines

<link rel="stylesheet" href="widget/chatbot.css" />
<script src="widget/chatbot.config.js"></script>
<script src="widget/chatbot.js" defer></script>
